VELCRO CONVERT — DEPLOYMENT SETUP
=================================

1. DEPLOY
   Pushing to the cPanel git repo runs .cpanel.yml, which copies this folder
   into the document root and removes dev-only files (tests, .env.test, etc.).
   The result looks like:

   ramp.usevelcro.com/
   ├── index.html        (page markup)
   ├── css/app.css       (page styles; style.css is the Tailwind build)
   ├── js/*.js           (page scripts, loaded in order by index.html)
   ├── index.php         (API front controller)
   ├── .htaccess
   ├── goat/             (admin dashboard)
   └── php-backend/
       ├── .env          (you create this, see step 3)
       └── data/         (created automatically)

2. DATABASE
   - Create a MySQL database and user in your hosting control panel.
   - Import php-backend/sql/schema.sql into that database. Newer tables
     (referrals, campaigns) are created automatically on first use.

3. ENVIRONMENT FILE
   - Copy php-backend/.env.example to php-backend/.env on the server.
   - Fill in ALL real values (database, Switch key, PAJ key, admin password,
     webhook secrets, callback URL, etc.).
   - ADMIN_PASSWORD should be a password_hash() value, not the plain password:
       php -r "echo password_hash('your-password', PASSWORD_DEFAULT), PHP_EOL;"
     Plain text and sha256:<hex> values still work but are weaker.
     Changing it logs out every admin session.
   - NEVER commit or share this .env file.

4. PERMISSIONS
   Make php-backend/data/ writable by PHP (chmod 755 or 775).

5. ADMIN DASHBOARD
   The admin dashboard is at /goat/. It trades the admin password for a
   12-hour session token; the password itself is never stored in the browser.

6. WEBHOOKS
   In your Switch and PAJ dashboards set:
     Switch webhook URL: https://yourdomain.com/webhook/switch
     PAJ webhook URL:    https://yourdomain.com/webhook/paj
   The webhook secrets must match the values in php-backend/.env.

7. CRON JOBS
   Set up these cron jobs in your hosting panel (adjust PHP path and folders):

   */2 * * * * /usr/bin/php /home/YOURUSER/public_html/php-backend/cron/poll.php >> /home/YOURUSER/public_html/php-backend/data/poll.log 2>&1
   0 0 * * * /usr/bin/php /home/YOURUSER/public_html/php-backend/cron/auto_withdraw.php >> /home/YOURUSER/public_html/php-backend/data/withdraw.log 2>&1
   0 * * * * /usr/bin/php /home/YOURUSER/public_html/php-backend/cron/cleanup_otps.php >> /home/YOURUSER/public_html/php-backend/data/cleanup.log 2>&1

8. HOSTFI (BTC / ETH sells)
   - Create a developer key in the HostFi portal (app.dev.hostcap.io for the
     sandbox, app.hostcap.io for live) and set HOSTFI_CLIENT_ID,
     HOSTFI_CLIENT_SECRET and HOSTFI_BASE_URL in php-backend/.env.
   - Settings -> Developers -> Webhook Subscriptions: subscribe
     https://yourdomain.com/webhook/hostfi to deposit and withdrawal events.
   - Fund the HostFi NGN wallet: every payout is sent from it.
   - Check Approvals in the HostFi portal: payouts that wait for manual
     approval are not "instant".
   - Coins, fee and timers are managed in /goat -> HostFi.

9. TEST
   Visit https://yourdomain.com/api/health — it should return dbConnected:true.

10. LOCAL CHECKS (before pushing)
   php php-backend/tests/unit_test.php
   php php-backend/tests/email_test.php
   php php-backend/tests/referral_test.php
   php php-backend/tests/security_test.php
   php php-backend/tests/hostfi_test.php
   After adding Tailwind classes to index.html or js/, rebuild style.css
   (command at the top of tailwind.config.js).
